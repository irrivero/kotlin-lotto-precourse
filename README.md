# Kotlin-Lotto

## Features to implement

### Basic Project Structure
- Set up the main classes and packages
- Create the entry point (Application class)

### Ticket Purchase
- Allow users to enter purchase amount
- Validate that the amount is divisible by 1,000 KRW
- Generate lottery tickets with 6 unique random numbers (1-45)

### Winning Numbers
- Allow users to enter 6 winning numbers
- Allow users to enter a bonus number
- Validate all inputs according to the requirements

### Statistics Calculation
- Check matches between purchased tickets and winning numbers
- Calculate prize amounts based on match count
- Display winning statistics and profit rate
